## &nbsp;✨ &nbsp;Features

<div align="center">

| &nbsp; | Feature | Description |
|:---:|---------|-------------|
| 🎨 | **Dark Luxury Tech** | Custom color system with deep navy & electric accents |
| 📌 | **Sticky Navbar** | Persistent across all pages while scrolling |
| 🖱️ | **Custom Cursor** | Magnetic hover effect on desktop |
| 📊 | **Scroll Progress Bar** | Live reading progress at the top of the page |
| 🌊 | **Canvas Animations** | Unique animated background on every single page |
| 💡 | **Scroll-Reveal** | Smooth IntersectionObserver-powered entry animations |
| 📈 | **Animated Skill Bars** | Trigger on scroll for dynamic visual impact |
| 🌙 | **Dark / Light Mode** | Toggle with localStorage persistence |
| 📱 | **Fully Responsive** | Mobile menu with smooth slide-in on all screen sizes |
| 🔐 | **Admin Dashboard** | Firebase authentication protected project manager |
| 📬 | **Contact Form** | Opens Gmail directly from the site |
| ⚡ | **Zero Dependencies** | Pure vanilla JS — no frameworks, no bloat |

## &nbsp;⚙️ &nbsp;Setup & Usage

### &nbsp;`1` &nbsp; Clone the repository
```bash
git clone https://github.com/hell-codes/prabinyadav-portfolio.git
cd prabinyadav-portfolio
```

### &nbsp;`2` &nbsp; Add your assets
```
images/logo.png        ←  your logo
images/profile.jpg     ←  your photo
resume.pdf             ←  your resume
certificates/          ←  your PDF certificates
```

### &nbsp;`3` &nbsp; Open locally
```bash
# Just open in browser — no build step needed
open index.html
```

### &nbsp;`4` &nbsp; Deploy

| Platform | Method |
|----------|--------|
| [GitHub Pages](https://pages.github.com) | Push to `gh-pages` branch |
| [Netlify](https://netlify.com) | Drag & drop the folder |
| [Vercel](https://vercel.com) | Import from GitHub |

## &nbsp;🔐 &nbsp;Admin Panel

The admin dashboard at `/admin/login.html` is protected by **Firebase Authentication**.

<details>
<summary><b>&nbsp;Click to expand admin setup guide</b></summary>

<br/>

- ✅ Login with your Firebase email/password
- ✅ Add projects with title, description & image
- ✅ Delete projects — changes reflect live on the site instantly
- ✅ Projects are stored in `localStorage`

> To set up your own Firebase project, update the config in `admin/login.html` and `admin/dashboard.html`.

</details>
