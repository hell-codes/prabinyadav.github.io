## 〈 01 〉&nbsp; What Makes This Different

<br/>

<table>
<tr>
<td width="50%" valign="top">

#### 🌊 &nbsp;Crafted with Intention

Every page has its own **unique animated Canvas background** — particles, waves, hexagons, orbs, falling lines, rising dots. None share a scene. Custom cursor, scroll progress bar, magnetic hover effects, animated skill bars — every interaction handcrafted in pure Vanilla JS.

> No Bootstrap. No Tailwind. No templates.
> Every pixel written with purpose.

</td>
<td width="50%" valign="top">

#### ⚡ &nbsp;Engineered with Precision

**Firebase Firestore** as live cloud backend — projects added from the admin panel appear for every visitor worldwide, instantly. Images auto-compress via Canvas API. `IntersectionObserver` powers all scroll animations. `overflow-x: clip` fixes sticky navbar. Zero npm packages.

> No build step. No node_modules.
> `open index.html` → it just works.

</td>
</tr>
</table>

## 〈 02 〉&nbsp; Features

<br/>

<div align="center">

|  | Feature | Description |
|:---:|:--------|:-----------|
| 🖱️ | **Custom Cursor** | Dot + lagging ring · Expands on hover · Hidden on touch via `(hover:none)` |
| 📊 | **Scroll Progress** | Gradient bar pinned at top · Fills as you read down the page |
| 🎨 | **Canvas Backgrounds** | 7 unique scenes — hand-coded · one per page · never repeated |
| 👁️ | **Scroll Reveal** | `IntersectionObserver` — elements animate only on viewport entry |
| ⌨️ | **Typing Animation** | 4 developer roles cycling with natural erase and retype |
| 📈 | **Animated Skill Bars** | Fill to exact percentage only after scrolled into view |
| 🌙 | **Dark / Light Mode** | One click · Saved to `localStorage` · Persists across all pages |
| 📱 | **Fully Responsive** | Hamburger menu · `clamp()` typography · CSS Grid · No Bootstrap |
| 🔐 | **Admin Dashboard** | Firebase Auth protected · Add and delete projects live |
| ☁️ | **Cloud Database** | Firebase Firestore · Real-time · All visitors see the same data |
| 🖼️ | **Image Compression** | Canvas → JPEG auto-compress before Firestore upload |
| 📬 | **Contact Form** | Opens Gmail compose pre-filled · Zero backend required |
| ⚡ | **Zero Dependencies** | No React · No Tailwind · No webpack · Pure browser APIs only |

## 〈 07 〉&nbsp; Getting Started

<br/>

```bash
# Clone the repository
git clone https://github.com/hell-codes/prabinyadav-portfolio.git
cd prabinyadav-portfolio

# Drop in your personal assets
# → images/logo.png
# → images/profile.jpg
# → resume.pdf
# → certificates/

# Open locally — no build step required
open index.html
# or: npx serve .
```

## 〈 08 〉&nbsp; Admin Panel

<br/>

> 🔐 &nbsp;`/admin/login.html` &nbsp;— &nbsp;Protected by Firebase Authentication

<details>
<summary><b>&nbsp;▸ &nbsp;Expand — Dashboard guide + Firebase setup</b></summary>
<br/>

| Action | Result |
|:-------|:-------|
| ➕ Add project | Title + description + image → compressed → Firestore → live instantly |
| 🗑️ Delete project | Removed from Firestore → gone from site for all visitors |

<br/>

```bash
# Firebase setup for your own fork
# 1. console.firebase.google.com → create project
# 2. Firestore Database → create (production mode)
# 3. Authentication → Email/Password → enable
# 4. Authentication → Users → add yourself
# 5. Replace firebaseConfig in login.html + dashboard.html
```

```javascript
// Firestore security rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /projects/{docId} {
      allow read:  if true;
      allow write: if request.auth != null;
    }
  }
}
```
